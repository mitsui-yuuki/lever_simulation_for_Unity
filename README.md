  # lever_simulation_for_Unity

  Unityで多段レバーをシミュレーションするためのプロジェクトです。

  ## 使用方法

  1. このリポジトリをクローンします。
  2. Unity Hubからクローンしたプロジェクトを開きます。
  3. UnityのProjectウィンドウで `Assets > Scenes` を開きます。
  4. `SampleScene` をダブルクリックして開きます。
  5. Unity上部の再生ボタンを押して実行します。

  > `SampleScene` を開かずに実行すると、レバーが表示されない場合があります。
